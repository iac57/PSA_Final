Existing Network Controls

Edit PV/reference voltage setpoints and fixed bus shunt compensation. Changes are staged until you run the AC power flow.

Bus classifications follow the MATPOWER bus matrix (column 2: PQ=1, PV=2, slack=3), even when PQ buses contain online generators. PQ generators retain their fixed P and Q injections. After editing the .m file, reload it to refresh classifications.

Generator voltage regulation

Run a power flow to display PV-bus Qg.

Qg is calculated by the power flow; the generator table flags Q-limit violations if the setpoint cannot be supported.

Fixed shunt compensation

Positive = capacitive injection; negative = inductive absorption. Actual reactive injection scales with |V|². Enter 0 to remove net susceptance.
